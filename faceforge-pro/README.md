# FaceForge Pro

Professional AI-powered face transformation web application.

## Features
- Real-time face detection
- Multiple AI transformations (age, beauty, style, effects)
- 100% browser-based processing
- No server costs
- PWA support for mobile

## Free AI Services Used
- Hugging Face Inference API (free tier)
- Replicate API (free tier)
- DeepAI API (free tier)
- TensorFlow.js for browser processing
- MediaPipe for face detection

## Setup
1. Clone repository
2. Get free API keys:
   - Hugging Face: https://huggingface.co/settings/tokens
   - Replicate: https://replicate.com/account/api-tokens
   - DeepAI: https://deepai.org/dashboard
3. Add keys to `js/api-services.js`
4. Deploy to GitHub Pages

## Deployment
